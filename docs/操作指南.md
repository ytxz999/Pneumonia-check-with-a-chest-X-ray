# 项目执行手册（给你的操作指南，做完可删）

## 你要做的事，按顺序

### 第 0 步：装环境（半天内搞定）

1. 确认电脑装了 Python 3.10+（终端运行 `python --version` 查看）
2. 在 `pneumonia-detection` 文件夹打开终端，逐条运行：

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

> 如果 torch 安装太慢，用国内镜像：
> `pip install torch torchvision -i https://pypi.tuna.tsinghua.edu.cn/simple`
> 如果想用 GPU 训练：先看 `nvidia-smi` 确认有 N 卡，再按 pytorch.org 官网命令装 CUDA 版。没有 GPU 也没关系，CPU 多等一会也能跑完。

### 第 1 步：下载数据集

1. 注册 Kaggle：https://www.kaggle.com （需要邮箱 + 可能需要梯子）
2. 打开 https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia
3. 点 Download（约 1.2 GB），解压
4. 把解压出来的 `chest_xray` 文件夹放进项目的 `data/` 文件夹
   （确认 `data/chest_xray/train/NORMAL/` 这种路径存在即可）

### 第 2 步：跑数据准备

```bash
python src/prepare_data.py
```
看到「✅ 数据集检查通过」和「验证集重新切分完成」就成功。

### 第 3 步：训练（核心步骤）

```bash
python src/train.py
```

- CPU 会比较慢（1~2 小时），挂着去干别的
- 急的话先 `python src/train.py --epochs 3` 快速验证流程通不通
- 结束后在 `results/` 里能看到混淆矩阵和训练曲线图，`models/` 里有 `best_model.pth`

### 第 4 步：Grad-CAM 热力图

```bash
python src/gradcam.py
```
`results/` 里多出 6 张「原图+热力图」对比图。挑 1~2 张效果好的放进 README。

### 第 5 步：网页 Demo

```bash
python app/app.py
```
浏览器打开 http://127.0.0.1:7860 ，拖一张测试集的胸片进去看效果。
**录个屏或截图**，放 README 和 PPT 里。

### 第 6 步：填 README + 写报告

- 把 `results/metrics.json` 里的数字填进 README 第 4 节的表格
- README 里所有「待填写」的地方补全
- 课程报告建议结构（每部分 1 页即可）：
  1. 背景与动机（抄 README 第 1 节改写）
  2. 数据集介绍（第 2 节 + 类别不平衡说明）
  3. 方法（第 3 节，迁移学习原理用自己的话讲）
  4. 实验结果（第 4 节 + 混淆矩阵分析，重点解释为什么看 Recall）
  5. 可解释性分析（第 5 节 + 你的观察）
  6. 局限与伦理（第 8 节改写——这是医学AI课程的加分重点）

## 常见问题

| 问题 | 解决 |
|---|---|
| `pip install` 报错/超时 | 加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 训练报显存不足 | 把 `train.py` 里 `BATCH_SIZE` 改成 16 |
| gradcam 报 import 错误 | 确认装的是 `grad-cam` 这个包（有连字符） |
| Kaggle 下载不了 | 用手机热点/梯子，或找同学拷贝数据集 |
| 训练太慢 | `--epochs 3` 先跑通，正式结果再跑 10 轮 |
